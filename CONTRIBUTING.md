# Contributing

Thanks for taking a look. First-time contributors are very welcome.

1. Pick an issue labeled good first issue, or open a new one to talk through your idea.
2. Fork the repo and make a branch: git checkout -b my-change
3. Install with pip install -r requirements.txt and run pytest to make sure everything passes.
4. Make your change and add a test for it.
5. Open a pull request and tell me what you changed and why.

Some ideas: a Schedule A command for itemized donors, a map of donations by state, bulk data support, and joining PAC giving with public scorecards for members of Congress.
